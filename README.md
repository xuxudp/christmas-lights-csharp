# 🎄 Christmas Lights - C#

A project developed to practice the basics of C# using .NET 8.

The goal is to create a simple Christmas lights animation in the console using colors and sequential lighting.

## 🎯 Objective

This project was created to practice basic C# concepts, such as:

- Variables
- Arrays
- Conditional statements
- Loops
- Operators
- Console applications
- Basic .NET project structure
- Git and GitHub

## 💡 How It Works

The program displays six colored Christmas lights.

One light is highlighted at a time, and the active position moves sequentially from one light to the next.

After reaching the last light, the animation returns to the first one and starts again.
