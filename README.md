# 🎄 Christmas Lights - C#

A beginner-friendly project developed to practice C# using .NET 8.

The current version runs in the console and creates a simple Christmas lights animation using colors and sequential lighting.

This is the first stage of the project. In future versions, the project will be expanded into a **web application**, allowing me to explore new concepts and technologies while maintaining the same Christmas Lights idea.

## 🎯 Objective

This project was created to practice C# concepts step by step, starting with the fundamentals before moving to more complex implementations.

The current console version focuses on:

- Variables
- Arrays
- Conditional statements
- Loops
- Operators
- Console applications
- Basic .NET project structure
- Git and GitHub

## 💡 How It Works

The program displays six colored Christmas lights.

One light is highlighted at a time, and the active position moves sequentially from one light to the next.

After reaching the last light, the animation returns to the first one and starts again.
